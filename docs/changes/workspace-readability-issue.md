# 활동 작업 흐름과 매칭 가독성 개선

## 문제

- 목표 상태를 바꾸면 API의 수정 시각 정렬 때문에 목록 맨 위로 이동한다.
- 목표 관리가 이번 주에 고정되어 날짜 이동·선택이 불가능하다.
- 활동 선택과 큰 진행률 안내가 반복되어 주요 도구가 늦게 보인다.
- 도구별 제목과 상태 구분이 약하고, 히트맵이 왼쪽에 치우쳐 있다.
- 매칭 필터와 카드가 가로로 길고 작은 강조 박스가 과도하다.
- 최근 보라색 세로 띠 제거와 홈 회전 로고가 실행 작업트리/커밋에 누락되었다.

## 완료 조건

- 등록 순서를 유지하며 진행 중 목표를 하이라이트, 완료 목표를 회색과 취소선으로 표시한다.
- 일/주/월 이전·다음·오늘·날짜 직접 선택이 작동하고 선택 기간으로 목표를 저장한다.
- 목표·히트맵 우선 기본 배치를 제공하고 개인이 편집한 배치는 보존한다.
- 히트맵 이름과 중앙 정렬을 적용하고 마감/다음 목표를 읽기 쉽게 정리한다.
- 매칭의 최대 폭과 카드 정보 밀도를 조정하고 검색/필터 기능을 유지한다.
- 최근 세로 띠 제거를 실행 작업트리에 반영하고 홈 로고 전환 주기를 4초로 변경한다.
- 실제 로컬 API/DB 연결 화면과 모바일 폭을 검증하고 스크린샷을 저장한다.
