# 끼리끼리 웹 설계 문서

이 디렉터리는 React Native 앱과 같은 Express API·MySQL 데이터를 사용하는 끼리끼리 웹의 구현 기준을 정의한다. 문서는 `develop` 브랜치의 현재 코드 상태를 기준으로 작성했으며, 구현 전 검토를 위한 목표 설계도 함께 포함한다.

## 공통 원칙

1. 앱과 웹은 같은 Express API와 MySQL DB를 단일 진실 공급원으로 사용한다.
2. 웹 클라이언트는 DB에 직접 접속하지 않는다.
3. 앱 화면을 확대 복사하지 않고, 같은 디자인 철학을 웹 사용 방식에 맞게 재배치한다.
4. 일반·학생·관리자와 학교·전국 권한은 서버 판정을 최종 기준으로 한다.
5. 화면은 `로딩`, `성공`, `빈 상태`, `오류`, `권한 없음`을 모두 정의한다.
6. 실제 계정, 비밀번호, 토큰, 운영 URL, SMTP·DB 설정값은 문서에 기록하지 않는다.

## 변경 관리

- 기능 구현으로 화면·API·DB 계약이 바뀌면 같은 PR에서 관련 문서를 갱신한다.
- DB 변경은 ERD와 마이그레이션 계획을 함께 수정한다.
- API 응답의 필드명이나 상태값이 바뀌면 API 명세와 프론트 도메인 타입을 함께 수정한다.
- 디자인 토큰 변경은 앱과 웹의 영향 범위를 PR 본문에 적는다.
