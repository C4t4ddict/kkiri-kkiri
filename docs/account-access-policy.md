# 회원·학교 인증 접근 정책

## 역할 기준

| 사용자 상태 | 활동 정보 | 전국 모집 | 본교 모집 | 운영 관리 |
| --- | --- | --- | --- | --- |
| 일반 회원 | 조회 가능 | 조회·작성·지원 가능 | 학교 이메일 인증 전 불가 | 불가 |
| 학교 인증 회원 | 조회 가능 | 조회·작성·지원 가능 | 인증한 같은 학교만 조회·작성·지원 가능 | 불가 |
| 관리자 | 조회 가능 | 일반 회원과 동일 | 관리자 계정에 학교 인증이 있을 때 해당 학교만 가능 | 가능 |

관리자 권한은 학교 범위를 우회하지 않습니다. 학교 전용 모집은 서비스 운영 기능과 별개로 인증한 학교가 같은 사용자만 접근합니다.

## 사용자 흐름

1. 회원가입 이메일을 인증합니다.
2. 등록된 `.ac.kr` 도메인으로 가입하면 학교 인증 회원으로 생성됩니다.
3. 일반 이메일로 가입한 회원은 마이페이지의 `학교 인증`에서 등록된 학교 이메일을 추가할 수 있습니다.
4. 모집 목록·상세·지원·초대·팀 합류 단계마다 서버가 학교 인증과 학교 도메인을 다시 확인합니다.
5. 전국 모집을 본교 모집으로 변경할 때 다른 학교 또는 미인증 상태의 유효 지원자가 있으면 변경을 거부합니다.

## 서버 강제 원칙

- 클라이언트의 탭·버튼 비활성화는 안내용이며 권한 판단의 최종 기준은 서버입니다.
- 모집 인원 집계는 모집글 응답의 집계값만 사용하고 전체 지원서 내용은 관리자 외 사용자에게 노출하지 않습니다.
- 활동 상세의 모집글 목록도 로그인 후에만 조회할 수 있습니다.
